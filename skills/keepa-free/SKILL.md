# Keepa Free Amazon Price Check

Determine whether a specific Amazon offer looks attractive relative to its visible Keepa price history, WITHOUT a Keepa API key or paid MCP server. Be useful even when the Amazon product page itself blocks agents.

## When to activate

Use this skill for a product URL (including `amzn.eu`, `amzn.to`, or `a.co`), an Amazon ASIN, a Keepa product link, or questions about historical prices, sale prices, and whether to buy now or wait.

## Prerequisites

- An HTTP-capable tool or browser for resolving redirects and opening Keepa pages.
- An image-capable tool or browser screenshot capability to interpret price charts. Text-only browsing cannot reliably analyze a PNG chart.
- Optional: standard-library-only `scripts/keepa_lookup.py`. Do not install packages or request credentials.

## Workflow

### 1. Find the ASIN without fetching an Amazon product page

Prefer the provided helper. Run it relative to this skill directory:

```bash
python3 scripts/keepa_lookup.py 'https://amzn.eu/d/<SHORT_CODE>'
```

For a standalone ASIN, specify the desired marketplace when it is not Germany:

```bash
python3 scripts/keepa_lookup.py B0EXAMPLE1 --marketplace de
```

The helper checks known Amazon URL patterns (`/dp/ASIN`, `/gp/product/ASIN`, `/gp/aw/d/ASIN`, and `?asin=...`) or follows short-link **HTTP redirect headers only**. It deliberately stops on reaching a normal Amazon URL. It does NOT need an Amazon HTML page. It returns JSON with the ASIN, detected marketplace, a clean Amazon product URL, a Keepa product URL, and a proposed image URL. Original query and affiliate/tracking parameters are discarded.

If the helper cannot run, inspect the URL, or use an HTTP/browser request for the shortener and read the `Location` redirect header. Never invent an ASIN. For a short link, do not assume the destination marketplace from the shortener's suffix (`amzn.eu` does not prove the destination is Amazon Germany).

### 2. Open the free Keepa chart if publicly accessible

Construct this **best-effort, unofficial** publicly used chart URL:

```text
https://graph.keepa.com/pricehistory.png?asin=ASIN&domain=MARKETPLACE&amazon=1&new=1&used=1&range=365
```

Example for Germany:

```text
https://graph.keepa.com/pricehistory.png?asin=B0EXAMPLE1&domain=de&amazon=1&new=1&used=1&range=365
```

Replace `ASIN` with the verified identifier and `MARKETPLACE` with `de`, `com`, `co.uk`, etc. The legacy `graph.keepa.com` URL has been publicly used without a key, but is **not a guaranteed public API**; it may be unavailable, restricted, or may return an image saying no price history exists. Do NOT substitute `api.keepa.com/graphimage`: Keepa's official Graph Image API requires a paid key and charges a token per image.

You can try a 90-day chart when the 365-day view is too compressed. Limit automated requests to a small number for individual research; respect access restrictions and rate limits. Do not bypass authentication, paywalls, CAPTCHAs, or anti-bot controls.

The optional helper can save a chart for vision analysis:

```bash
python3 scripts/keepa_lookup.py B0EXAMPLE1 --marketplace de --download-chart /tmp/keepa-price.png
```

**Important:** HTTP 200 or a PNG file is not proof of data. Inspect the actual image and verify that it contains relevant product price traces, axes and dates. Error graphics, placeholders, empty charts, stale data, and missing series are NOT valid price history.

### 3. Fallback: Keepa's free interactive product view

Visit the Keepa link generated by the helper:

```text
https://keepa.com/#!product/3-B0EXAMPLE1
```

This example uses marketplace ID `3` for Germany; never reuse that ID for a different country. The Keepa site is a JavaScript application. A browser that can render the page and capture a screenshot may be necessary. Keepa may require an account or limit some features. Do not try to reverse-engineer or scrape private internal endpoints.

If both image and website access fail, provide the Keepa product URL and clearly explain that an image or screenshot from the user is required for visual analysis. Do not fabricate chart findings.

### 4. Read the chart carefully

- Identify the marketplace, date range, currency and product/variant. A different size, color, bundle, or marketplace is not a reliable comparison.
- Read the **legend** to distinguish Amazon's own price, third-party new, and used. Do not assume colors are universal.
- Check for visible historical lows, typical levels, large temporary spikes, recent trend and seasonal promotions.
- Distinguish a plotted most-recent value from a **verified live offer**. The chart's most recent reading may be old, and prices can change after tracking updates.
- If the user gives a current price, label it as **user-provided**, not independently verified. If no current price is verifiable, do not pronounce a discount definitively good or bad.
- Quote exact prices only when readable as labels, tooltips, or unambiguous tick marks. Otherwise use approximate ranges and label them estimates. Do not claim to calculate exact medians or percentiles from image pixels alone.
- Treat apparent Amazon crossed-out list prices as marketing context, not a trustworthy historical baseline.

### 5. Answer in a compact, decision-oriented way

Use this format, omitting unknown values rather than filling gaps:

**Product:** [verified title if visible, otherwise ASIN]
**Marketplace:** [observed domain]
**Current price:** [verified, user-provided, or unavailable]
**History period:** [visible dates or range]
**Historical low:** [approximate/exact, price series, if readable]
**Usual price range:** [approximate, price series, if readable]
**Verdict:** [Good / Fair / Wait / Insufficient evidence] with a short reason.
**Suggested target:** [optional, evidence-based; otherwise omitted]
**Sources:** [Keepa product URL] and [chart URL if actually readable].

Confidence is **low** when the chart is illegible, missing the relevant series, old, or not matched to the same variant. Never say an item is at its all-time low without inspecting the all-time range.

## Privacy and limits

Never copy real user-provided product URLs, shortened links, account status, delivery area, order details, merchant baskets, tracking query parameters or local screenshots into a public repository, skill examples, test fixtures or commit messages. Public examples must use synthetic identifiers, and browser/session credentials remain private. The command emits canonical Amazon URLs stripped of user or affiliate tracking parameters. Short-link resolution visits Amazon's redirect infrastructure, not arbitrary third-party resolvers.

**Important:** This is an ASIN and price-history skill, not a complete present-day Amazon offer comparison. For live Amazon seller listings, multiple pack sizes, Prime/non-Prime shipping, returns and unit value, invoke `amazon-free` and the `shopping-compare` coordinator.

## Errors and boundaries

- Short link fails to resolve: report the unresolved short link; ask for a full product URL, an ASIN, or a user screenshot. Never make one up.
- Amazon blocks the page: continue with redirect metadata or Keepa; there is no need to bypass Amazon's block.
- Keepa chart shows "no data" or requires a login: say that history is unavailable in this free route, not that the product never had a lower price.
- Keepa images are blocked to this agent: use an interactive browser only if available, or request a screenshot.
- A screenshot omits labels, axes or dates: avoid numerical conclusions.
- Do not scrape seller data or request credentials. Do not use an unauthorized proxy or paid API.
